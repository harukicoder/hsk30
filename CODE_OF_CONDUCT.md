# Code of conduct

This is a small project. The rule is: be decent, assume good faith, and keep
disagreement about the work rather than the person.

Concretely — participants are expected to be respectful in issues, pull requests
and email; to accept correction without rancour, since being wrong about a
standard is the normal condition here; and to avoid harassment, personal
attacks, and derogatory comments of any kind.

Chinese language teaching spans several political jurisdictions with genuinely
different standards and conventions. Discussion of the technical differences
between them is the substance of this project and is welcome. Using the project
as a venue for political argument is not.

Unacceptable behaviour can be reported to alvaro.serrano.gp@gmail.com. Reports
will be read and acted on; the maintainer may remove comments, close threads, or
block accounts. There is no committee — one person reads these, and will say
what was done.
