Paste Chinese text and see the HSK level a reader needs, against either document called "HSK 3.0": the 2025 exam syllabus, which the exam uses from 13 December 2026, or the 2021 national standard GF0025-2021. The result says which one it used, and what the other would say.

Built on [hsk30](https://github.com/harukicoder/hsk30) (doi:10.5281/zenodo.22234657). Source for this Space: `space/` in that repository.
